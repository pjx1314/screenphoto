# 内部结构

本仓库为单一 Cargo package，包含 `screenphoto` 核心库、同名命令行程序和 `screenphoto-dev` 维护工具。所有入口共用同一条渲染管线。

## 模块职责

- `src/lib.rs`：导出 `render_bytes` 和 `render_rgb`，公开 `limits` 模块和 `Error` 类型，核心渲染不触碰文件系统或网络。
- `src/limits.rs`：定义输入字节上限、输入像素上限和输出长边上限。
- `src/calibration.rs`：集中存放相机姿态、屏幕网格和玻璃反光参数，同时收纳传感器和编码配置，不对外暴露。
- `src/color.rs`：维护 sRGB 查表和 Rec.709 亮度权重，计算直方图自动曝光、白平衡偏移和 Filmic 色调映射。
- `src/render.rs`：校验输入，解码 PNG 与 JPEG，处理 EXIF 方向旋转和透明白底合成，最后编码 JPEG。
- `src/pipeline.rs`：按固定顺序串起几何与光学阶段，为各阶段分配独立随机流。
- `src/frame.rs`、`src/rng.rs`：提供线性光浮点 RGB 缓冲和确定性随机数生成器。
- `src/geometry.rs`：计算针孔相机取景、单应矩阵和镜头径向畸变，执行受限裁切与面积平均预缩小。
- `src/optics/`：处理离焦暗角、重采样和屏幕子像素载波，再叠加反光泛光、传感器噪声、Bayer 插值与锐化。
- `src/cli/`：拆分参数定义和输入输出计划，负责文件原子写入与单行 JSON 报告。
- `src/capture.rs`：通过 Windows GDI 抓取显示器或虚拟桌面像素，直接转交 `render_rgb`。
- `src/bin/screenphoto-dev.rs`、`src/devtools/`：校验测试集，生成样图，运行基准测试并打包技能目录。

## 成像管线

1. 解码与测光：编码输入解码为 RGB8，执行 EXIF 方向变换并将透明像素合成到白底。抓屏输入直接使用 RGB8。自动曝光用固定 3 KiB 栈空间统计三通道 256 级直方图，经 sRGB 查表算出线性光均值。曝光结果不受重复纹理的像素相位影响。
2. 取景与离焦：按随机偏航、俯仰和滚转角计算针孔透视矩阵，再按有效采样域居中裁切。单轴两端合计最多裁切 10%，超限时自动收敛倾角。大图缩小时先在线性光下做面积平均预滤波，再把缩放并入透视矩阵。双线性逆向采样后，按像素到镜头中心的距离混合两档离焦核，最后叠加暗角。
3. 屏幕网格：按透视矩阵和镜头畸变计算每个像素的局部空间频率，叠加 RGB 竖条纹与水平行间隙。载波直接复用空间模糊阶段的离散核系数，算出带符号的二维频响。两种离焦频响按同一位置权重混合，再乘上像素孔径衰减。核系数在像素循环外预计算，零径向畸变时跳过径向坐标和雅可比矩阵运算。
4. 环境反光：独立随机流在上方 ±60° 范围内决定亮侧方向，并加入水平偏移。反光先在低分辨率网格生成并模糊，放大到四分之一边长的辅助缓冲。随后经共享透视矩阵映射，再放大回输出尺寸。泛光保留内部校准字段，默认强度为 `0`。
5. 传感器与色彩：叠加散粒噪声、色度噪声和水平条带，经 RGGB Bayer 采样与插值重建彩色摩尔纹。接着调整白平衡与 Filmic 色调映射，最后完成 sRGB 编码和轻度锐化。
6. 图像编码：量化为 RGB8，输出质量 `92`、色度采样 `4:2:0` 的无 EXIF JPEG。

默认配置将 `lens_distortion` 设为 `0`，模拟手机计算摄影校正后的成片效果，界面直线保持笔直。内部标定开启非零径向畸变时，畸变与透视同步参与安全边界拟合，随机流抽取顺序保持不变。

## 工作尺寸

- 编码输入大小限制在 `1 B..=40 MiB`，所有入口的像素总数不超过 `24,000,000`。
- 渲染与输出长边均为 `min(原图长边, 1920)`，短边按原图宽高比缩放且最小为 `1` 像素。
- 取景保证原图中央 90% 宽高区域留在画面内。镜头边界超出范围时最多二分搜索 12 次缩减变形幅度。裁切直接合成进采样矩阵，输出分辨率不变，不做二次缩放。
- 截图采样点的中心全部落在原图有效像素内，不在边缘延展重复像素。宽度或高度为 `1` 像素的输入退化为正面取景。低分辨率反光层允许延展边缘像素。
- 面积平均预滤波只分配不超过输出尺寸的浮点缓冲，不为大图创建原图尺寸的浮点副本。原图无需缩小时直接在采样阶段查表解码。
- 反光辅助缓冲边长为输出尺寸的四分之一。初始反光梯度按辅助缓冲的四分之一生成，相当于输出边长的十六分之一。离焦模糊与 Bayer 重建复用已有缓冲以压低峰值内存。

## 复现规则

`seed` 为 `None` 时，`render_bytes` 和 `render_rgb` 从系统随机源抽取一个 31-bit 非负整数，并在元组第二项返回。调用方显式传入 `Some(seed)` 时可使用完整的 `u64` 范围。

管线内部派生 5 条独立随机流：

- `stream 0`：相机偏航、俯仰和滚转姿态。
- `stream 1`：屏幕节距、镜头中心、径向畸变和采样相位。
- `stream 2`：传感器噪声。
- `stream 3`：白平衡增益偏移。
- `stream 4`：环境反光角度与偏移。

在同一输入、同一 `seed`、同一编译版本和同一目标平台上，输出字节一致。跨平台或跨编译器版本可能因浮点运算差异出现细微差别。

## 文件读写

- `shot` 读取输入文件时最多读取 `MAX_INPUT_BYTES + 1` 字节，超限立即中止，不把超大文件完整读入内存。读取前先拒绝指向原图的路径、符号链接和硬链接。
- 默认输出名直接在去掉扩展名的源文件名后拼接 `-photo.jpg`，全程使用操作系统原生字符串。非 UTF-8 路径只在终端输出或 JSON 报告中替换为可显示字符。
- 输出先写入目标目录内的短名称临时文件，执行 `sync_all` 刷盘后再原子替换目标路径，Unix 调用 `rename`，Windows 调用 `MoveFileExW`。临时文件名不拼接目标文件名，255 字节等达到文件系统长度上限的目标名也能正常写入。
- 创建临时文件遇到同名冲突时保留既有文件不删除。写入或替换失败时只清理本次新建的临时文件，目标路径原有的旧文件保持完好。
- 发布的平台包只含 `SKILL.md`、`LICENSE` 和对应平台的单文件可执行程序，Linux 采用 musl 静态链接，Windows 采用 MSVC `+crt-static`。
