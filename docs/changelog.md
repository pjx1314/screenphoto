# 更新记录

## 0.1.0

### 分发形式

- 提供 `screenphoto` 命令行程序，包含 `shot` 截图转换和 Windows `capture` 桌面抓屏。同时导出 `render_bytes` 和 `render_rgb` 库函数，并附带 Agent Skill。
- 支持 PNG 和 JPEG 输入，自动处理 EXIF 方向、灰度转换和透明白底合成，输出无 EXIF 的拍屏 JPEG。
- 支持通过 `default-features = false` 单独引入无文件、无网络依赖的渲染核心。
- 提供 Linux `x86_64` musl 静态包和 Windows `x86_64` MSVC 静态 CRT 技能包，推送 `v*` 标签时经 CI 校验后自动发布。

### 成像效果

- 默认关闭径向镜头畸变，保留斜拍透视和轻微旋转，消除页面鼓面感并保持直线笔直。
- 按有效采样区域自动居中裁切，单轴两端合计不超过 10%。超限时自动收敛姿态倾角，消除边缘像素拉伸。
- 大图缩小时先在线性光下做面积平均预滤波，减轻细线、表格和小字文本的混叠。
- 离焦模糊与屏幕子像素载波共用同一套离散核系数和位置权重，保留带符号的二维频响。零径向畸变下跳过冗余坐标和雅可比计算。
- 自动曝光改用全图三通道直方图计算线性亮度均值，消除周期纹理下的曝光跳变。
- 环境反光使用独立随机流控制亮侧角度和水平偏移，关闭默认泛光以减少无效开销。

### 文件安全

- 输出先写入同目录短名称临时文件并刷盘，再原子替换目标文件。目标文件名达到文件系统长度上限时仍能正常写入。
- 临时文件创建遇到冲突时保留既有文件。写入或替换失败时只清理本次新建的临时文件，不覆盖原图，也不破坏已有输出。
- Unix 默认输出名直接拼接源文件的原始字节，防止非 UTF-8 文件名折叠成同名输出。
- 标准输出写入失败时返回退出码 `1`，并将错误诊断输出到标准错误。
